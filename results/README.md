# Results Directory

Output artefacts from RSO protein design runs. Contents are generated by
the pipeline; nothing here should be manually edited.

## Structure

```
results/
├── runs/
│   └── <run_id>/                  # Per-run subdirectory (timestamped or named)
│       ├── designed_sequences.fasta   # Designed sequences in FASTA format
│       ├── backbone.pdb               # Input fixed backbone used
│       ├── designs/                   # Per-design output PDBs
│       ├── metadata.json              # Run parameters, config snapshot, times
│       └── status.json                # run status (running / done / failed)
└── metrics/
    ├── all_candidates.csv         # Flat table: one row per designed candidate
    └── backbone_summary.csv       # Aggregated stats per input backbone
```
